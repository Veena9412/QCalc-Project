# QCalc-Project
QCalc is a modular Java-based calculator application built to demonstrate Object-Oriented Programming (OOP) principles, debugging, and unit testing. The project showcases how different types of calculators can be designed and extended using inheritance and clean code practices.
Features:
1. **Standard Calculator**
  Basic arithmetic: addition, subtraction, multiplication, division.
  Floating-point support with method overloading.
2. **Scientific Calculator**
  Advanced operations: power, square root, trigonometric functions.
  Demonstrates inheritance and extension of core calculator logic
3. **Logic Calculator**
  Boolean operations: AND, OR, NOT, XOR
  Useful for digital logic and computer science fundamentals
